M5PaperS3-PocketFrame

v1.2.0
M5PaperS3 用の画像ビューア / デジタルフォトフレームアプリ。
ブラウザからワンクリックで書き込みできます。
Image viewer / digital photo frame for M5PaperS3.
Flash directly from your browser with one click.
お使いのブラウザは Web Serial に対応していません。
Google Chrome または Microsoft Edge（デスクトップ版）をお使いください。
Your browser does not support Web Serial.
Please use Google Chrome or Microsoft Edge (desktop).
HTTPS required. / HTTPS 接続が必要です。

使い方

  1. M5PaperS3 を USB-C ケーブルで PC に接続
  2. 上の 「Install」ボタン をクリック
  3. シリアルポートを選択（「USB JTAG/serial debug unit」など）
  4. 書き込み完了を待つ（約 30 秒）
  5. SD カードに JPG/PNG 画像を入れて挿入
  6. 電源ボタンで起動！

How to Use

  1. Connect M5PaperS3 to PC via USB-C cable
  2. Click the "Install" button above
  3. Select the serial port ("USB JTAG/serial debug unit", etc.)
  4. Wait for flashing to complete (~30 seconds)
  5. Insert SD card with JPG/PNG images
  6. Press power button to start!
⚠ Chrome / Edge のデスクトップ版が必要です（スマホ不可）。
初回接続時にドライバが自動インストールされない場合は、 ESP32-S3 USB ドライバを手動で入れてください。
⚠ Requires Chrome / Edge desktop (not mobile).
If the driver isn't installed automatically on first connection, manually install the ESP32-S3 USB driver.
